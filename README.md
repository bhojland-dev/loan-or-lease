# Lån eller leasing

Webapp der sammenligner TCO for køb (med billån) og privatleasing af samme bil. Forretningslogikken er beskrevet i `SPEC.md`.

```bash
npm install
npm run dev     # udviklingsserver
npm test        # tests (Vitest)
npm run build   # produktionsbuild til dist/
```

Deployes automatisk til GitHub Pages ved push til `main`.
